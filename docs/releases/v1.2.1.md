## Fixes

- **Album artwork from Spotifast.** Covers from Spotifast (and other players that hand Windows a cover file without an extension) now show up. After skipping, the new track's cover also replaces the previous one reliably. ([#1](https://github.com/Linux5Real/L4-Windows-NotchBar/issues/1))
- **Smoother opening animation.** The toolbar icons no longer shimmer while the notch opens. ([#3](https://github.com/Linux5Real/L4-Windows-NotchBar/issues/3))
- **Discord setup.** The guide now says to add `http://localhost` as a redirect in the Discord developer portal. Without it, Discord kept asking for permission in a loop. Already set up and working? Nothing to do. ([#2](https://github.com/Linux5Real/L4-Windows-NotchBar/issues/2))
