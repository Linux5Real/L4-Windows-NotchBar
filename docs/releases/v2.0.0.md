## New tools: text from any image and a translator

### Text from any image — OCR

- **Text aus Bild.** Screenshot a region or the whole screen, or paste an image from the clipboard, and the notch reads the text with Windows' own OCR — fully on your PC, nothing is uploaded. Leave the language on auto or pick one of the OCR languages installed in Windows.
- **Copy or forward.** Copy the result with one click, or send it straight to the translator.
- **Local only.** The recognition runs on your machine; the image never leaves it.

### Translator

- **Free, no account.** Translate text with a click — paste it, or forward it from the OCR tool. The language you used last is remembered.
- **Auto-detects the source.** Leave the source on auto and the result names the detected language.
- **Fails over.** Several free endpoints are tried in order; when one is down or rate-limited, the next takes over. Needs an internet connection — requests go directly to the translation endpoints, nothing is stored except your last text and languages.

## Ask grows up

- **No API key needed.** Notch now runs its own local OpenCode server (loopback only, random password per start, never leaves your PC) and the free OpenCode models work out of the box — no account, no key. Your existing Claude, ChatGPT, OpenRouter and custom setups keep working exactly as before.
- **The assistant can act, not just answer.** Ask now operates the notch: it creates notes, to-dos and timers, switches tabs, toggles focus and presentation mode, sets the volume, changes settings (language, units, closed look), opens any installed app by name (fuzzy match over the Start menu) and plays music — Spotify if it's running or installed, otherwise YouTube Music in the browser. The same protocol works with every provider, and only the actions implemented in the app are allowed — the assistant can't run arbitrary code.
- **Chat or Studio.** *Chat* answers and acts on the notch (notes, timers, tabs, music and more), but never touches files or runs commands. *Studio* works in a dedicated **Notch Studio** folder and may write files and run commands there — switch under **Settings → AI** and to allow, ask or deny for file and command access.
- **Grouped model picker.** **Settings → AI** lists the models per provider under section headings and loads them on demand — no more blind IDs, and the free ones are in the list.
- **Markdown answers.** Code blocks, lists and links render properly now, and a separate switch shows or hides the model's reasoning.
- **History you control.** Keep the chat across restarts with **Settings → AI → save chat history** (off by default, stored on your PC). Without it, history lives in memory only.

## Also new

- **Size for the notch and the line.** **Settings → Display → Size** scales the closed notch and the line in four steps, from small to extra large. The open panel keeps each tool's size.
- **A hotkey per tool.** Each tool can register its own global hotkey under **Settings → Tools** — press it and the notch opens straight in that tool.
- **Notes and to-dos now survive restarts.** They used to live in memory only; both are stored on your PC now.
- **Clipboard: text preview.** Click any copied text to preview it in the notch — long entries, URLs included — without opening anything; in presentation mode a click still just copies.
- **The line shows alerts too.** A finished timer or a prayer opens the thin line into the notch until you dismiss it — with the timer as before, and prayer as an optional alert.
- **Prayer times.** Optional tool with offline-calculated times for your location (follows the weather location), a quiet banner and an optional adhan. Enable under **Settings → Tools**.

## Polish

- **Grouped select menus** for long lists (model picker): section headings, scrollable, wider than the trigger.
- **Privacy dots follow the notch size** and stay centered next to the imagined camera.
- **Arabic interface gets its own typefaces** — Noto Sans Arabic across the UI, IBM Plex Sans Arabic for the prayer times.
